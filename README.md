<h2 align="center">🚀 Overview</h2>

<p align="center">
Cloud-Space is a <b>modern full-stack cloud storage platform</b> that allows users to upload, manage, and access files securely.
Built with scalability, speed, and security at its core.
</p>

<hr>

<h2 align="center">✨ Features</h2>

<p align="center">
🔐 Authentication • 📁 Upload/Download • ☁️ Cloud Storage <br>
⚡ Fast Backend • 🛡️ Secure System • 📱 Responsive UI
</p>

<hr>

<h2 align="center">🛠️ Tech Stack</h2>

<p align="center">
<b>Frontend:</b> HTML • CSS • JavaScript <br>
<b>Backend:</b> Node.js • Express.js <br>
<b>Database:</b> MongoDB
</p>

## 🧠 Architecture Notes

- 🌐 `public/` → Frontend UI & client-side logic  
- 🐍 `python-scripts/` → Background processing & utilities  
- ⚙️ `python-server/` → API services & backend logic  
- 🧩 `utils/` → Shared helpers  
- 📚 `docs/` → Documentation & architecture

## 🔧 Environment Setup

```env
GOOGLE_CLIENT_ID=ENTER_YOUR_GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET=ENTER_YOUR_GOOGLE_CLIENT_SECRET
GOOGLE_REDIRECT_URI=ENTER_YOUR_GOOGLE_REDIRECT_URI
GOOGLE_API_KEY=ENTER_YOUR_GOOGLE_API_KEY

FB_APP_ID=ENTER_YOUR_FACEBOOK_APP_ID
FB_APP_SECRET=ENTER_YOUR_FACEBOOK_APP_SECRET

TWITTER_KEY=ENTER_YOUR_TWITTER_KEY
TWITTER_SECRET=ENTER_YOUR_TWITTER_SECRET

MONGO_URI=ENTER_YOUR_MONGODB_URI

EMAIL_USER=ENTER_YOUR_EMAIL
EMAIL_PASS=ENTER_YOUR_EMAIL_APP_PASSWORD

PORT=5000
BASE_URL=http://localhost:5000
ENABLE_NGROK=true
NGROK_AUTHTOKEN=ENTER_YOUR_NGROK_AUTH_TOKEN
FILES_META=./filesMeta.json

SUPER_ADMIN_EMAIL=owner@cloudspace.com
SUPER_ADMIN_PASSWORD=ENTER_SUPER_ADMIN_PASSWORD
ADMIN_EMAIL=admin@cloudspace.com
ADMIN_PASSWORD=ENTER_ADMIN_PASSWORD
ADMIN_PRIVACY_PIN=ENTER_ADMIN_PIN

COUPON_CODE=GET50
DISCOUNT_PERCENT=50
UPI_ID=ENTER_YOUR_UPI_ID
UPI_NAME=ENTER_YOUR_NAME
PRICE_PER_TB=450

COINS_DISCOUNT_ENABLED=true
COINS_PER_RUPEE=5

JWT_SECRET=ENTER_STRONG_RANDOM_SECRET
SYNC_FOLDER=./uploads
TERABOX_EMAIL=ENTER_TERABOX_EMAIL
TERABOX_PASSWORD=ENTER_TERABOX_PASSWORD
AUTO_GENERATE_PLANS=true
```

## 🌱 Initial Setup Guide

- Set MongoDB URI  
- Configure Email credentials  
- Setup Admin login  
- Upload files via UI or `/uploads`  
- Customize pricing & coupons

## ⚠️ Security Note

> Never commit `.env` file  
> Keep credentials private
