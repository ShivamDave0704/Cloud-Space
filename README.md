<h2 align="center">🚀 Overview</h2>

<p align="center">
Cloud-Space is a <b>modern full-stack cloud storage platform</b> that allows users to upload, manage, and access files securely.
Built with scalability, speed, and security at its core.
</p>

<p align="center">
🔐 Authentication • 📁 Upload/Download • ☁️ Cloud Storage <br>
⚡ Fast Backend • 🛡️ Secure System • 📱 Responsive UI
</p>

## 🔧 Environment Setup

```env
# 🔐 OAuth Credentials
GOOGLE_CLIENT_ID=YOUR_GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET=YOUR_GOOGLE_CLIENT_SECRET
GOOGLE_REDIRECT_URI=YOUR_REDIRECT_URI

FB_APP_ID=YOUR_FACEBOOK_APP_ID
FB_APP_SECRET=YOUR_FACEBOOK_SECRET

# 🗄️ Database
MONGO_URI=YOUR_MONGODB_URI

# 📧 Email Service
EMAIL_USER=YOUR_EMAIL
EMAIL_PASS=YOUR_APP_PASSWORD

# ⚙️ Server Config
PORT=5000
BASE_URL=http://localhost:5000

# 🔑 Security
JWT_SECRET=YOUR_STRONG_SECRET

# 👑 Admin Setup
SUPER_ADMIN_EMAIL=owner@cloudspace.com
SUPER_ADMIN_PASSWORD=YOUR_PASSWORD

# 💰 Pricing & Offers
COUPON_CODE=GET50
DISCOUNT_PERCENT=50
PRICE_PER_TB=450

# ☁️ Storage
SYNC_FOLDER=./uploads
```

---

## 🌱 Initial Setup Guide

- Set MongoDB URI  
- Configure Email credentials  
- Setup Admin login  
- Upload files via UI or `/uploads`  
- Customize pricing & coupons  

---

## ⚠️ Security Note

> Never commit `.env` file  
> Keep credentials private
