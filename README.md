<h2>🚀 Overview</h2>
<p>
Cloud-Space is a powerful full-stack cloud storage application that allows users to securely upload, manage, and download files.
It is designed with scalability, security, and performance in mind.
</p>

<hr>

<h2>✨ Features</h2>

<ul>
  <li>🔐 User Authentication (Login / Signup)</li>
  <li>📁 File Upload & Download</li>
  <li>☁️ Cloud Storage System</li>
  <li>⚡ Fast & Scalable Backend</li>
  <li>🛡️ Secure Data Handling</li>
  <li>📱 Responsive UI Design</li>
</ul>
